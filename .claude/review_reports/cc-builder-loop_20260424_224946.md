## 详细分析

### 1. locate-state.sh 的 case 条件 bug

**Line 92**：
```bash
if [ "$CWD" = "$wt_abs" ] || case "$CWD" in "$wt_abs"/*) true;; *) false;; esac; then
```

在 POSIX shell 的 `case` 语句中，pattern 不会被 `$` 展开。这里 `"$wt_abs"/*` 会当成字面字符串与 `$CWD` 匹配，不会变成 `"/path/to/wt/*"`。应改为：

```bash
if [ "$CWD" = "$wt_abs" ] || [ -z "${CWD##$wt_abs/*}" ]; then
```

或用数组：
```bash
if case "$CWD" in "$wt_abs"/*) true;; *) false;; esac; then
```

**但这样仍不对**。正确修法：
```bash
if [[ "$CWD" = "$wt_abs" || "$CWD" = "$wt_abs"/* ]]; then
```
或用 POSIX 兼容写法：
```bash
if [ "$CWD" = "$wt_abs" ] || echo "$CWD" | grep -q "^$(printf '%s\n' "$wt_abs" | sed 's/[[\.*^$/]/\\&/g')/"; then
```

最简单是改为：
```bash
if [ "$CWD" = "$wt_abs" ] || case "$CWD/" in "$wt_abs"/*) true;; *) false;; esac; then
```

### 2. setup-builder-loop.sh 的并发竞态

**Line 140-154**：
```bash
if [ -f "$STATE_FILE" ]; then
  EXIST_ACTIVE="$(grep -E '^active:' "$STATE_FILE" | head -1 | awk '{print $2}')"
  ...
  if [ "$EXIST_ACTIVE" = "true" ]; then
    if [ -z "$EXIST_WT" ] || [ -d "$EXIST_WT" ]; then
      echo "❌ 同 slug (${SLUG}) 已有 active loop，state=${STATE_FILE}" >&2
      exit 4
    fi
```

**竞态场景**：
1. setup A 到 line 141，检查：$STATE_FILE 存在？是的，读取 EXIST_ACTIVE=true
2. setup B 同时到 line 141，检查：$STATE_FILE 存在？**还是**是的
3. A 进 if，读 EXIST_ACTIVE=true，检查 EXIST_WT，发现目录存在，exit 4 拒绝 ✓
4. 但 B 也读了 EXIST_ACTIVE=true，两者互不知道，都会尝试写

**根本原因**：缺 flock 原子性。应该在 line 124 后加：
```bash
STATE_LOCK="${STATE_DIR}/.lock"
exec {FD_LOCK}>"$STATE_LOCK"
flock "$FD_LOCK" || { echo "❌ 无法获取 lock"; exit 5; }
```

然后在写完后：
```bash
flock -u "$FD_LOCK"
exec {FD_LOCK}>&-
```

方案文档第 149 行有提到 flock，但实现没有。

### 4. GC 中的 pipefail 表达式

**setup-builder-loop.sh:132**：
```bash
_wt="$(grep -E '^worktree_path:' "$_sf" 2>/dev/null | head -1 | sed -E 's/...')"
```

若 state 文件无 `worktree_path:` 行，grep 返回 1，管道中 `set -euo pipefail` 会导致脚本挂掉。虽然这行在 for 循环里，循环会继续，但仍不明确。建议改为：
```bash
_wt="$(grep -E '^worktree_path:' "$_sf" 2>/dev/null | head -1 | sed -E 's/...' || true)"
```

或更直接：
```bash
_wt="$(grep -E '^worktree_path:' "$_sf" 2>/dev/null | sed -E 's/...' || echo '')"
```

### 5. test-parallel-loop.sh 的文件匹配模糊

**Line 73-76**：
```bash
STATE_A="$(cd "$STATE_DIR" && ls -1 *alpha*.yml | head -1)"
STATE_A="${TMP}/${STATE_DIR}/${STATE_A}"
```

若 state 目录下有多个含 "alpha" 的文件（虽不太可能），`ls -1` 会返回多行，拼路径时会错。应该用：
```bash
STATE_A="$(find "$STATE_DIR" -maxdepth 1 -name '*alpha*.yml' | head -1)"
```
