- builder.md 错误分类依赖关键词匹配 （error message substring grep）
- 若 API 改版改变措辞（如 "unsupported_parameter" → "parameter not supported"），需手动更新关键词列表
- 建议：commit message 中明确列出关键词版本，future API 升级时追踪

- live smoke 子测构造最小 diff（"+print('hello')"），无法验证复杂 diff 的 reviewer 行为
- 建议：如有条件可在 CI/CD 中补充真实 builder 改动的冒烟（但方案已明确为可选，现阶段足够）
